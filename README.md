**Lectores Compulsivos**

**Lectores Compulsivos** es una aplicación web desarrollada en **Flask y Python** para la gestión comunitaria de una biblioteca, permitiendo un control eficiente de préstamos, usuarios, stock y sugerencias.

**Características Principales:**

•	Sistema de Autenticación y Solicitudes: Control de acceso seguro para usuarios y administradores, con un flujo de aprobación donde los nuevos registros requieren validación previa por parte de un administrador.
•	Catálogo Interactivo: Visualización de libros con portadas personalizables, categorías detalladas, sinopsis y control automático de disponibilidad de stock.
•	Gestión de Alquileres y Préstamos: Préstamos configurados por 7, 14 o 21 días con indicadores visuales de estado y cálculo automático de fechas exactas al solicitar extensiones de plazo.
•	Cola de Espera Inteligente: Sistema de turnos para libros agotados que reasigna automáticamente el ejemplar al siguiente usuario en la fila al confirmarse una devolución.
•	Sugerencias de Libros: Espacio para que los usuarios propongan nuevos títulos con comentarios opcionales, respaldado por un panel de administración para visualizar y eliminar registros.
•	Diseño Moderno: Interfaz adaptada con Bootstrap 5 en modo oscuro, efectos visuales de desenfoque en el acceso y soporte para favicon personalizado.

**¿Qué utilizamos?**
•	Backend: Python 3, Flask
•	Seguridad: Werkzeug Security para hashes de contraseñas y gestión de sesiones
•	Frontend: HTML5, Jinja2, Bootstrap 5, CSS personalizado
•	Persistencia de Datos: Almacenamiento local mediante archivos JSON estructurados
